# SMS bank: every text the funnel sends

Five texts. Each one is under 160 characters with the link and the opt-out line, so it goes out as one plain SMS.

## Rules for every text

- **Consent first.** Only text a number that ticked the text consent line. [HUNTER: the step-1 form needs that line before any text goes out.]
- **Brand first.** Every text starts with "Child Phenoms:" so the parent knows who it is.
- **Opt-out last.** Every text ends with the line "Reply STOP to opt out." Honor STOP at once. Reply to HELP with hello@childphenoms.com.
- **Quiet hours.** Send between 8 a.m. and 8 p.m. in the parent's time zone. Hold anything that falls outside until 8:30 a.m.
- **One link.** Plain ASCII only. No emoji, no curly quotes. Either one turns the text into a shorter, pricier message type.
- **Test number:** send every text to 9857681025 first. No other test numbers.

Counts include the link and the opt-out line. Texts with `{{first_name}}` show how many letters the name can have and still fit under 160.
