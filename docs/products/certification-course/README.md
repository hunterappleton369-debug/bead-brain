## Time

- **Video.** About 110 minutes of script at 130 words a minute (5 to 7 minutes a lesson). On-screen demos add to that.
- **Lesson time.** 29 hours across the 20 lessons (video, drills, teach-back, check), plus a 1-hour exam: **30 hours**, the figure on the page.
- **Pace.** Six weeks at about five hours a week. Week 1: L01–L04. Week 2: L05–L07. Week 3: L08–L10. Week 4: L11–L14. Week 5: L15–L17. Week 6: L18–L20 and the exam.

## How the problems were made

No arithmetic in this folder was typed by hand. `tools/build.mjs` imports `js/soroban.js` and `js/generator.js`, seeds the random numbers per lesson (so a change to one lesson never reshuffles another), builds each drill set to its lesson's allowed moves (the same `allow` and `require` lists as `js/curriculum.js`), re-runs every problem on the soroban model, and refuses to write if any problem uses a move the lesson has not taught. Products, quotients, remainders and flash totals are re-computed. Then `tools/xcheck.py` checks everything again with a separate Python model.

```
cd docs/products/certification-course
node tools/build.mjs            # fill lessons, exam form A, run times
node tools/build.mjs --check    # verify only
node tools/build.mjs --form D   # write a fresh retake form (exam-form-d.md + key)
node tools/build.mjs --stats    # script words and run times
python3 tools/xcheck.py         # independent re-check
```

Last run: `build.mjs` 440 items generated and verified, 0 bad. Forms B and C, 26 items each, 0 bad. `xcheck.py` 371 answers re-checked, 0 bad.

To print: `npx md-to-pdf lessons/L01.md` (MIT, https://github.com/simonhaenisch/md-to-pdf). `<div class="page-break"></div>` splits the exam into parts.

## Frameworks used

- **Perfect Webinar order** in L01 (big promise, origin story, the one thing, three secrets), so instructors give parents the same talk in the same order. L01 also carries the allowed and forbidden claims from BUILD-BRIEF §1.4. Source: Russell Brunson, summarised at https://www.clickfunnels.com/blog/hook-story-offer/ and https://www.shortform.com/blog/russell-brunson-sales-funnel/ .
- **Proven-program structure** in L11 to L18: UCMAS modules and class format, the three Japanese ladders (bead, anzan, flash anzan), accuracy before speed, a graded test per level. Sources: https://www.ucmas.com/ , `docs/RESEARCH-NOTES.md`, BUILD-BRIEF §3, https://www.guinnessworldrecords.com/world-records/fastest-flash-mental-arithmetic .
- **Value ladder** in L12 and L20: every family an instructor teaches is sent to the free kit and University for the daily 15 minutes.

## Move order

Settled 2026-10-21: every carry and borrow works the rod you are on first, then the rod to its left. Adding takes away the friend, then carries. Taking away adds the friend, then borrows ("Minus 9: add 1, borrow 1 from the left"), the same order as the trainer's spoken lines. L07, L08, L09, L19 and the exam keys teach it.
