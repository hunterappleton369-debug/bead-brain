# Class drills: the 8-week starter course

One printable page per class for the instructor, matched to `class-plans.md`. Every problem was made by the site's own generator and checked against the bead moves taught that week, so no child meets a move they have not learned.

Print the week's page for each child (drill A and B), and keep one copy with the warm-up and flash lists for yourself. Answers are at the end of the file. Rebuild with `node docs/products/instructor-launch-kit/tools/make-class-drills.mjs`.
