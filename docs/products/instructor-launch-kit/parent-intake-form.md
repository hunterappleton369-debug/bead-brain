# Parent intake form

The short form each family fills in before class 1. Copy it into a Google Form or print it. It takes about two minutes.

## Note for the instructor

- Ask only for what you need to run a safe class. Do not add fields for school name, birth date or last name of the child unless you truly need them.
- Keep the answers private. Store them where only you can see them, and delete them when the child stops coming to class.
- The app profile you set up for the child uses a first name and age only.
