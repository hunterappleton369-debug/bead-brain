# Lesson index

Every lesson and quest card in the Prodigy Secrets Program, in order. The program has **76 lessons and 28 quest drills**, 104 pages of drills in all, plus 10 boss tests.

The lessons follow the trainer one for one. A lesson is done when the drill hits its pass mark. Quest cards are short review drills for Fridays. Boss tests close each stage.
